# Кинотеатр Султана

Отдельная Android TV-first версия приложения. Рабочая ветка: `sultan-cinema-tv`. Исходные ветки `main` и `talking-musa-rebuild` не меняются.

## Первый конвейерный этап

- Android TV-интерфейс с управлением пультом и кинематографической заставкой.
- Каталог использует API Internet Archive и ограничивает выдачу материалами с Public Domain Mark 1.0 или CC0 1.0.
- Перед воспроизведением приложение повторно проверяет лицензию элемента и ищет MP4-файл.
- Встроенный плеер построен на AndroidX Media3 ExoPlayer.
- Избранное хранится локально на устройстве.
- Раздел 18+ скрыт за кодом 123 и подтверждением возраста; реальный каталог законных 18+ источников пока не подключён.

## Ограничение каталога

Приложение не размещает фильмы и не обходит платные сервисы. Оно показывает только элементы, у которых в метаданных Internet Archive явно указана лицензия Public Domain Mark 1.0 или CC0 1.0. Сам факт наличия видео на стороннем сайте не считается разрешением на использование.

## Сборка

GitHub Actions собирает APK при обновлении ветки `sultan-cinema-tv`. APK и контрольная SHA-256 сумма публикуются как артефакт запуска workflow.

Package: `com.sultan.cinema`
