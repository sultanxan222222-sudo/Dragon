# Каталоги источников 18+

Этот справочник содержит только названия, категории и главные страницы внешних сайтов. В него не включены видеоматериалы, прямые потоковые URL, парсеры, скрейперы, обходы ограничений или резолверы.

## Источники данных

- AdultHideout: https://github.com/Vashiel/repository.adulthideout — каталог сайтов из `plugin.video.adulthideout/resources/website_catalog.json`; лицензия репозитория GPL-2.0. Справочник подготовлен на основе версии 1.0.27, commit `36bf9f9a86985491cf6bdbad8958738683f6cd80`.
- Hedon Haven: https://github.com/Hedon-Haven/Hedon-Haven — README указывает Pornhub и xHamster; оба сайта уже есть в каталоге AdultHideout. Проект лицензирован AGPL-3.0.

## Ограничения

- Наличие сайта в списке не означает одобрения, проверки возраста посетителей, прав на конкретный ролик или разрешения на его скачивание/повторную трансляцию.
- Пять источников, связанные по названию/назначению с утечками либо сексуальным насилием, отмечены как отключённые; сайты без проверенного адреса тоже неактивны.
- Переход выполняется на сайт-источник. Каталог не извлекает и не воспроизводит сторонние потоки.
